# Search — Índice de Busca
## Descrição
Índice de busca unificado para objetos de qualquer tipo da plataforma.
## Responsabilidades
- Indexação de objetos por tipo e ID
- Busca textual com metadados
- Atualização automática via signals
## Modelo
- SearchIndex: registro indexado com conteúdo e metadados
## Dependências
- Nenhuma
